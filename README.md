## Project Description

Moonlit Library is a fully functional online bookstore web application built with HTML5, CSS3, and JavaScript. It features a curated collection of classic and modern books displayed in an interactive carousel, with a dark/light theme toggle inspired by a moonlit aesthetic.

---

## Features

- **Responsive Navigation** — sticky header with anchor links and a hamburger menu on mobile
- **Hero / Welcome Section** — introduction to the bookstore with a call-to-action button
- **Featured Books Carousel** — 7 books displayed in a centred carousel; inactive cards are faded, the active card is in full focus; supports arrow buttons, dot indicators, keyboard navigation (← →), and touch swipe
- **Interactive Book Descriptions** — clicking "Read More" on the active card reveals a short description; navigating away resets it automatically
- **Contact Form with Validation** — validates that all fields are filled and that the email address is correctly formatted, with live error feedback
- **Dynamic Footer** — displays the current date and time, updated every second
- **Dark / Light Mode Toggle** — switches between a soft lavender day theme and a deep navy night theme; preference is saved in localStorage
